# 순서도 작업 공간과 UI 보완 검토

2026-09-12 · 기준 `df293d8` · 작업 브랜치 `codex/flowchart-workspace-polish`

## 변경 이유와 결과

기획서가 240px로 제한되어 제목과 추가 버튼이 끊겼고, 실행 패널을 접으면 ‘디버거’라는 이름이 임의로 줄바꿈되었습니다. 기획서를 300~320px로 넓히고 실행 패널을 최초에 접어 캔버스 공간을 확보했습니다. 엔트리와의 연결을 위해 세로 기호 보관함과 직접 드래그하는 동작은 유지했습니다.

접힌 패널은 전체를 누를 수 있는 ‘실행 과정’ 세로 버튼으로 표시하며 키보드 펼침과 초점 복귀를 지원합니다. 실행해도 자동으로 펼쳐지지 않으며 최근 출력·오류 메시지는 캔버스 위에서 확인합니다. 패널을 펼치면 캔버스의 보이는 폭은 줄지만 블록 좌표는 유지됩니다. 필요하면 빈 캔버스를 끌어 작업 영역을 이동할 수 있습니다.

네 기호의 드래그 미리보기를 Canvas API로 그려 평행사변형·마름모가 직사각형으로 보이는 문제를 해결했습니다. 실제 배치 중심은 도형 크기, 캔버스 이동과 확대 배율을 반영합니다. 취소 시 미리보기를 정리하고, 새 기호를 휴지통으로 끄는 동작은 기존 선택 블록 삭제와 구분합니다.

다섯 단계의 공통 프레임을 맞추고 좁은 화면의 단계 메뉴 넘침을 수정했습니다. 홈 중복 버튼을 제거하되 로고로 돌아가는 경로는 유지했습니다. 수행평가 버튼은 별도의 경계로 구분하고 학습 코스는 작은 색상 강조를 적용했습니다. 점수와 교사 검토 상태를 분리하고 ‘자동 채점 참고 점수’로 문구를 바로잡았습니다. 채점·인증·저장 정책은 변경하지 않았습니다.

## 검증

로컬 Edge/Chromium, Windows, 모의 Firebase 서비스 환경입니다. 실제 로그인·AI·운영 DB 쓰기를 수행하지 않았습니다.

* `node tools/check.cjs`: 35개 스크립트 문법과 로컬 HTML 자산 참조 통과.
* `node --test --test-isolation=none tests/core.test.cjs tests/api.test.cjs tests/rounds.test.cjs`: 기존 기능 검사 12개 통과.
* `node tests/browser.cjs`: 학생·교사 모의 시나리오 23개 통과. 제거된 홈 버튼 대신 로고의 평가 중 잠금을 검사하도록 갱신했습니다. [결과](../tests/results/browser.json)
* `node tests/workspace-ui.cjs`: UI 회귀 시나리오 5개 통과. [결과](../tests/results/workspace-ui.json)

UI 검사는 390/768/1024/1440/1920px에서 1→2→3→4→5→3 단계 전환 시 탐색 영역 위치·높이·본문 시작 위치를 비교합니다. 패널 조작은 901px 경계를 포함해 확인하며, 블록 데이터가 바뀌지 않고 실행·제출 버튼에 접근 가능한지 검사합니다. 실제 마우스 드래그로 네 기호 추가, 미리보기 픽셀의 투명 영역, 캔버스 이동·확대 후 배치 중심, 취소·휴지통 동작을 확인합니다. 실행 중 접힌 상태 유지와 출력 표시, 점수/검토 상태 분리도 확인합니다. 두 브라우저 검사 모두 페이지 예외·콘솔 오류 0개입니다.
