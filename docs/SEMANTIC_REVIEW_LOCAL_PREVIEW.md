# 의미 기반 AI 설계 점검과 로컬 체험

2026-09-14 KST. 현재 작업 브랜치 `codex/semantic-flowchart-review`, 기준 커밋 `46b644b`. 이번 변경과 직전 튜터·교사 진입 변경은 로컬 상태이며 원격 푸시·병합·배포하지 않았습니다.

## 변경 이유와 동작

자연어 ‘현재기온 입력 → 출력’은 순차 구조지만, 기존 분석은 순차 카드 2개에 처리 기호 2개가 필요하다고 계산했습니다. 이 잘못된 분석을 AI에도 전달하여 불필요한 저장·처리를 추가하라고 조언했습니다.

`js/core/flowchart-review.js`에서 구조 사실과 의미 검토를 분리했습니다. 순차 카드와 처리 기호의 개수를 맞추지 않으며, 입력 기호 자체로 값을 받아 저장할 수 있음을 명시합니다. 자연어와 순서도의 여러 단계·기호가 함께 같은 동작을 표현하는 것도 허용합니다. AI는 내용과 연결 방향, 예/아니오 분기를 보고 검토합니다. 입력 자료는 별도 user JSON으로 전달하고 검토 지침은 system 메시지에 둡니다. 입력 자료에 포함된 지시문을 따르지 않도록 안내하지만 프롬프트만으로 모든 오판·주입 공격을 제거한다고 보장하지 않습니다.

화면 위치로 반복 연결을 추정하던 규칙은 실제 방향 그래프의 순환 탐색으로 바꿨습니다. 구조 검사를 통과해도 의미가 맞다는 결론은 내리지 않습니다. AI 첫 줄의 명시적 판정과 설명이 유효해야 하며, 구조 통과와 AI 통과를 함께 만족해야 제출됩니다. 기존 수정 후 재검사·지연 응답 무효화는 유지합니다. 수행평가의 도움·배점은 변경하지 않습니다.

변수 표는 변수 수에 따라 늘어나 콘솔을 아래로 밀고, 콘솔 최소 높이 140px를 남긴 뒤 내부 스크롤로 전환합니다. 긴 값은 줄바꿈하고 표 제목을 고정합니다. 키보드로도 마지막 변수까지 접근할 수 있습니다.

## 로컬 체험 방법과 보안 범위

1. `node tools/preview.cjs --ai` 실행.
2. http://127.0.0.1:4174/index.html?demo=1 접속.
3. 교사용 → 임시 로그인에서 `.env.preview.local`의 `LOCAL_TEACHER_PASSWORD=` 오른쪽 값을 입력.
4. 종료 시 터미널 Ctrl+C. 기본 4173 미리보기에는 실제 AI가 없습니다.

로컬 교사 로그인은 운영 Firebase 교사 계정 등록과 무관하며 실제 학생 기록에 접근하지 않습니다. 평가는 로컬 시연으로 유지하고 수행평가 AI 채점을 실제 연결하는 기능은 추가하지 않았습니다. AI 튜터와 일반 실습 AI 요청만 기존 운영 `/api/chat`으로 전달합니다. 실제 AI 사용량이 발생하며 서버가 Firebase 익명 인증 계정을 생성하고 운영 API가 호출량을 기록합니다. 따라서 모든 원격 쓰기가 없는 모드는 아닙니다. 학생 답안·성적·교사 역할 문서는 읽거나 쓰지 않습니다. AI에 보낸 입력은 기존 운영 AI 처리 경로를 거칩니다.

AI 비밀 키를 로컬에 내려받지 않습니다. Firebase 인증 토큰은 서버 메모리에만 보관하고 브라우저에 전달하지 않습니다. 로컬 비밀번호는 자동 생성한 파일에만 보관하며 Git 및 Vercel 배포에서 제외됩니다. 브라우저에는 8시간 만료의 로컬 세션 토큰만 sessionStorage에 둡니다. 공유 PC의 다른 OS 사용자가 파일을 읽지 못하게 하는 것은 해당 PC의 파일 접근 권한에 달려 있습니다.

서버는 127.0.0.1에만 바인딩하고 Host·Origin·서버별 임의 토큰·JSON 형식을 검사합니다. 외부 사이트 요청을 차단하고 AI는 분당 5회·실행당 30회, 로그인은 분당 5회로 제한합니다. 요청 크기도 제한하며 서버 오류에 비밀 값이 포함되지 않도록 안내를 감쌉니다. 이 도구는 개발 PC용이며 인터넷에 공개할 서버로 사용하지 않습니다.

로컬 로그인 어댑터가 로드되지 않으면 기본 무비밀번호 시연으로 후퇴하지 않고 로그인을 거부합니다. 같은 PC의 프로세스는 loopback에 접근할 수 있고, 기존 외부 CDN 스크립트도 페이지 권한으로 실행됩니다. 임의 토큰을 이들에 대한 인증 경계로 간주하지 않습니다. 비정상적으로 매우 큰 순서도 자료의 추가 방어와 긴 입력의 세분화된 오류 안내는 남은 개선점입니다.
