교사 화면에 준비·시작·강제 마감 버튼이 동시에 노출되어 현재 상태와 다음 동작을 구분하기 어려웠습니다. 상태 안내와 한 개의 조작 버튼으로 정리했습니다. 사용자는 간단한 검증 후 병합·배포까지 승인했습니다.

| 상태 | 버튼 | 안내 |
|---|---|---|
| 준비 전 | 평가 준비 | 학생 입장을 받을 회차 준비 |
| 입장 대기 | 평가 시작 | 입장 인원 확인, 30분 평가 |
| 평가 중 | 평가 종료 | 남은 시간·제출 인원, 종료 확인 |
| 평가 종료 | 새 평가 준비 | 이전 답안 보관·새 회차 입장 안내 |

처리 중 버튼과 학급 선택을 잠급니다. 실패하면 현재 상태와 오류를 함께 보여 주며, 완료 알림을 별도 팝업으로 띄우지 않습니다. 종료 문구는 모든 답안을 서버가 즉시 제출한 것처럼 표현하지 않고 연결된 학생 화면에 제출을 요청한다고 설명합니다. 회차·상태 비교를 트랜잭션에 추가해 다른 교사가 연 새 회차를 오래된 종료 요청으로 마감하지 않게 했습니다.

평가 상태의 Firestore 구독에는 메타데이터 변경을 포함합니다. 교사 화면은 아직 서버에 반영되지 않은 로컬 쓰기 이벤트를 완료로 표시하지 않습니다. 학생의 기존 평가 동작과 권한 규칙은 유지합니다. 시간 만료 표시 자체는 DB를 변경하지 않습니다.
