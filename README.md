# 🎓 알고리즘 랩 (Algorithm Lab 2.0) - 교사용 가이드 및 매뉴얼

이 프로젝트는 중·고등학교 정보 교과 '알고리즘과 프로그래밍' 단원을 위한 통합 인터랙티브 실습 웹앱입니다.  
전문적인 웹 프로그래밍 지식이 없어도 **문제 텍스트와 설정을 손쉽게 수정**하고, **Netlify로 전 세계에 배포**하며, **띵커보드(ThinkerBoard)로 학생 과제를 3초 만에 취합**할 수 있습니다.

## 🧭 2. 순서도 연구소 2.0 (3단계 레벨 안내)

3코스 '순서도 연구소'는 학생들의 인지적 발달 단계에 맞추어 3단계로 점진적 확장됩니다:

1. **🔰 Level 1. 기초 퍼즐 챌린지**:
   * 라면 끓이기(순차), 놀이기구 탑승(선택), 도어락 비밀번호(반복) 슬롯 맞추기.
   * 표준 순서도 기호(단말·입출력·처리·판단)와 기본 제어 구조 체득.
2. **🛠️ Level 2. 예시 공방 (선생님과 함께 손풀기)**:
   * "지각 방지 아침 등교 알고리즘" 추천 예시를 보며 블록 글자 수정법과 스마트 유도등 선 잇기 학습.
3. **🚀 Level 3. 나만의 백지 공방 (종합 설계)**:
   * **좌측 [자연어 기획서]**: `[🩺 추상화 재료 가져오기]`로 1코스 처방전 재료를 불러와 3대 자연어 카드(순차·선택·반복) 조립.
   * **우측 [자유 순서도 캔버스]**: 블록을 무제한 꺼내 글자를 수정하고, **스마트 유도등(초록 네온 발광)**을 따라 화살표 연결.
   * **판단(◇) 기호의 반복 루프 특권**: 역방향 연결은 오직 판단 기호에서만 허용되어 '반복의 원리'를 체득.
   * **Solar AI 설계 검사**: `[🔍 Solar AI에게 알고리즘 검사 받기]` 클릭 시 자연어와 순서도의 일치도 피드백 제공.

## 📋 3. 띵커보드(ThinkerBoard) 3초 제출 워크플로우

수업 종료 5분 전, 학생들의 과제를 다운로드 폴더 미아 없이 한눈에 수거할 수 있습니다:

1. 학생이 우측 하단의 **`[🎉 내 알고리즘 완성 및 띵커보드 제출]`** 버튼을 누릅니다.
2. 팝업창에서 학번과 이름을 입력하면, 문제 분석부터 순서도 다이어그램, AI 총평까지 담긴 **한 장짜리 인포그래픽 포트폴리오 카드**가 생성됩니다.
3. **`[📋 띵커보드 제출용 이미지 복사 (Ctrl+V)]`** 버튼을 누르면:
   * 이미지가 컴퓨터 클립보드에 '사진' 형태로 찰칵 복사됩니다.
4. 학생은 선생님이 칠판에 띄워주신 **띵커보드 화면에서 `+` 누르고 `Ctrl + V`**만 누르면 3초 만에 제출 완료!
   *(클립보드가 제한된 PC를 위해 `[💾 이미지 파일 저장]` 버튼도 함께 제공됩니다.)*
