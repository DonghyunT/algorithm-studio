## 🧭 2. 3대 교육과정 코스 & 순서도 연구소 5단계 로드맵

### 💡 1코스. 문제 추상화 실습실 (생각 다이어트 연구소)
* **[1단계 30초 맛보기]**: 상태(초기·현재·목표)와 조건의 개념을 1:1 맞춤 카드로 직관적 체득.
* **[2단계 실전 워크북]**: 일상 문제에서 불필요한 노이즈를 덜어내는 '생각 다이어트' 후 AI 처방전 발행.

### 🤖 2코스. 알고리즘 설계 실습실 (샌드위치 로봇 연구소)
* 샌드위치 조리 명령어를 순서대로 조립하며 로봇의 엉뚱한 행동 관찰.
* 알고리즘 5대 조건(입력·출력·명확성·유한성·수행가능성)을 자연스럽게 검증하고 **'오류 찾기와 수정'** 수행.

### 📐 3코스. 순서도 연구소 (점진적 5단계 스캐폴딩)
학생들의 인지적 부담을 덜어주기 위해 5단계로 정교하게 확장됩니다:

1. **🍜 Step 1. 순차 구조 (라면 끓이기)**:
   * 시작부터 종료까지 일직선으로 진행되는 기본 순차 흐름 조립 (슬롯 교체 복구 지원).
2. **🎡 Step 2. 선택 구조 (놀이기구 탑승 판정기)**:
   * 마름모(◇) 판단 기호를 통해 키 조건에 따라 '탑승 가능'과 '탑승 불가'로 갈라지는 분기 체득.
3. **🔒 Step 3. 반복 구조 (도어락 비밀번호 검증)**:
   * 비밀번호 불일치 시 다시 입력 단계로 되돌아가는 루프백(Loopback) 구조 완성.
4. **🛠️ Step 4. 예시 공방 (지각 방지 아침 등교 알고리즘)**:
   * **[자연어 ↔ 순서도 1:1 실행 시뮬레이션]**: 상단 `[▶ 실행 시뮬레이션]` 클릭 시 좌측 자연어 카드와 우측 순서도 기호/선이 발맞추어 단계별 동시 점멸.
   * **[대화형 판단 체험]**: 07:30 기준 시간 도달 시 학생이 직접 `[✓ 07:20 (예 ➔ 밥 먹기)]` 또는 `[✗ 07:45 (아니오 ➔ 즉시 출발)]`을 선택하여 분기 체험.
5. **🚀 Step 5. 나만의 백지 공방 (풀스크린 4단 스튜디오)**:
   * **네이버 메일형 와이드 스튜디오**: 100vw × 100vh 전면 활용, 기존 화면 대비 캔버스 400px+ 확장.
   * **[1단: 자연어 기획서]**: 1코스 추상화 처방전을 불러와 3대 제어구조 레시피 카드 조립.
   * **[2단: 기호 보관함]**: 엔트리 표준 색상 4대 기호(**🟣 단말, 🟢 자료, 🟠 판단, 🔵 처리**) 팔레트.
   * **[3단: 무한 캔버스]**: Manhattan 직각 꺾임 라우팅, 자석 스냅 포트, 상단 통합 실행 제어 바.
   * **[4단: 디버거 스튜디오]**: 실시간 변수 추적기(Watcher: 직전값·현재값 감지) & 터미널 콘솔(Console).
   * **[하이브리드 시뮬레이션]**: 비수식 일상 조건("배가 고픈가?")은 참/거짓 대화형 팝업으로, 수식 조건("x > 10")은 순수 JS AST 엔진이 자동 평가하여 네온 빛 흐름으로 시각화.

## 📋 3. 띵커보드(ThinkerBoard) 3초 제출 워크플로우

수업 종료 5분 전, 30명이 넘는 학생들의 과제를 다운로드 폴더 미아 없이 한눈에 수거할 수 있습니다:

```text
[AI 설계 검사 합격(💮)] ➔ [💮 띵커보드 제출 클릭] ➔ [학번/이름 입력] ➔ [📋 제출용 이미지 복사] ➔ [띵커보드에서 Ctrl + V!]
```

1. **3단 게이트웨이 인증**:
   * JS 구조 검사(판단 분기 완결, 고립 블록 검출, 더미 텍스트 방지)와 Solar AI 정성 분석이 모두 통과해야만 제출 버튼 잠금 해제.
2. **순수 Canvas 2D 고해상도 벡터 캡처**:
   * 외부 캡처 라이브러리 없이 순수 HTML5 Canvas API로 실제 학생이 배치한 캔버스 전체를 1:1 미니어처로 렌더링.
   * 자동 줄바꿈(`drawWrappedText`)으로 글자 겹침이나 잘림 없는 완벽한 포트폴리오 카드 생성.
3. **3초 제출 UX**:
   * 클립보드에 사진 형태로 바로 복사되므로, 선생님이 칠판에 띄워주신 **띵커보드/패들릿에서 `+` 누르고 `Ctrl + V`**만 누르면 즉시 제출 완료! (비상용 이미지 다운로드 지원)

## 🛠️ 4. 선생님을 위한 1초 유지보수 가이드

### Q1. AI API 키나 모델 버전을 바꾸고 싶을 때
👉 **`js/data/config.js`** 파일을 열어 API 키와 모델명을 수정하세요:
```javascript
export const CONFIG = {
  UPSTAGE_API_KEY: "선생님의_UPSTAGE_API_키",
  SOLAR_MODEL: "solar-pro4", // 기본 권장 최신 모델
};
```

### Q2. 순서도 기초 퍼즐이나 예시 문제를 수정하고 싶을 때
👉 **`js/data/flowchart-missions.js`**를 열어 Step 1~3 미션 데이터나 Step 4 추천 예시 텍스트를 원하는 수업 주제로 수정하세요.

### Q3. 학생들에게 배포할 때 (Netlify 무료 호스팅)
👉 [Netlify](https://www.netlify.com) 로그인 ➔ **Add new site** ➔ **Deploy manually** ➔ **이 프로젝트 폴더를 통째로 드래그 앤 드롭**하면 10초 만에 전 세계 어디서나 접속 가능한 학생용 URL이 생성됩니다!

### Q4. 컴퓨터실 수업 후 이전 반 학생의 데이터가 남아있지 않나요?
👉 본 스튜디오는 학교 공유 PC 환경을 고려하여 `localStorage`를 일절 쓰지 않고 **오직 `sessionStorage`만 사용**합니다. 브라우저 창을 닫으면 모든 작업 데이터가 깨끗이 초기화되어 다음 반 학생이 항상 깨끗한 첫 화면으로 수업을 시작할 수 있습니다.
